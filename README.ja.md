# Video Face Redactor / 動画顔ぼかし

動画内の顔をブラウザだけで検出・追跡し、**モザイク / ぼかし / 塗りつぶし / 絵文字**で隠してMP4へ書き出す、Browser Kitty向けの単一HTMLツールです。

画像版 `htmlapps-face-redactor` の **YuNet + ONNX Runtime Web** を再利用し、動画I/Oを **WebCodecs + MP4Box.js** で実装しています。選択した動画をアプリがサーバーへアップロードすることはありません。

## v1.0.0 の主な機能

- MP4 / MOV の読み込み
- H.264/AVC・H.265/HEVCをWebCodecsでデコード（HEVCはブラウザ・端末対応時）
- 入力コーデック・WebCodecsデコーダ・出力H.264エンコーダを別々に互換性表示
- `avc1.640033` など入力動画の実際のprofile/levelを使った `VideoDecoder.isConfigSupported()` 判定
- 動画読み込み後、既定設定（5fps）でYuNet顔検出を自動開始（1 / 2 / 5 / 10 fpsから再解析可能）
- IoU + 中心距離 + サイズ類似度による軽量顔トラッキング
- 検出キーフレーム間の補間
- 小さい顔 12 / 24 / 48 px プリセット
- 隠す範囲の余白調整（設定欄に加え、スマホではプレビュー内の小さな `− / ＋` 操作から変更可能）
- モザイク / ぼかし / 塗りつぶし / **絵文字**
- 手動で隠す範囲の適用時間を **1コマだけ / 前後1秒 / 前後3秒 / 前後5秒 / 動画全体** から選択
- 手動で隠す範囲ごとに、動きに合わせて位置をつなぐか / 同じ位置を保つかを選択・後から変更
- 前後1フレーム送りと連続再生による確認（`requestVideoFrameCallback()` 対応ブラウザでは実際の動画フレーム提示に同期）
- 最終実フレームの追加顔解析と、終端近くの顔トラックを動画末尾まで保持する漏れ対策
- タイムライン確認と不安定トラックの確認マーカー
- WebCodecs VideoEncoderによるH.264再エンコード
- AAC音声の無変換コピー（対応する入力のみ）
- 元解像度 / 1080p / 720p
- 画質プリセット
- 書き出すMP4のファイル名を指定可能
- 日本語 / 英語
- 実行時ネットワーク通信をCSPで遮断
- 単一HTML + 自己解凍HTML

> 顔検出・追跡は完全ではありません。書き出した動画を共有する前に、必ず動画全体を確認してください。

## スマートフォンUI

600px以下では、テンプレート標準のSafe Area対応固定ボトムナビを表示します。`動画 / 顔検出 / 確認・編集 / 隠し方 / 保存` へすぐ移動できます。顔検出中はプレビュー上にも進捗率とバーを表示するため、設定欄まで戻らなくても処理状況を確認できます。`隠し方` はプレビュー直下に表示され、モザイク・ぼかし・塗りつぶし・絵文字を横4列の選択ボタンで切り替えられます。モザイク/ぼかしには「弱め / 標準 / 強め」のプリセットを用意し、手動設定の時間と追い方もスマホ向けのタップ操作にしています。保存は解析完了まで無効です。

## 使い方

1. MP4 / MOV動画を選択します。左側のファイル選択に加え、空のプレビュー画面からも選択できます。
2. 動画を読み込むと、既定設定で**顔検出が自動開始**します。設定を変えた場合は **顔を見つける** で再解析できます。顔を探し終わるまでは書き出しボタンは有効になりません。
3. **確認・編集** では **1コマ前 / 1コマ次** で細かく確認するか、**連続再生** で動画全体を通して確認します。連続再生中の状態表示は「再生中」に固定し、停止した場面だけ「この場面で確認済み / 前後から位置を予測」を控えめに表示します。特に最後の1コマまで確認してください。
4. **隠し方** でモザイク / ぼかし / 塗りつぶし / 絵文字を選びます。スマホでは動画のすぐ下で選べるため、プレビューを確認しながら切り替えられます。隠せていない場所があれば **この場面に手動で追加** を使います。適用時間は1コマだけ・前後1/3/5秒・動画全体から選べ、動きに合わせるか位置を固定するかも選べます。一覧の手動設定を押すと、その場所へプレビューが移動し、黄色の枠をドラッグして位置を調整できます。
5. 絵文字はクイック選択または任意入力ができます。モザイク/ぼかしは強さも調整できます。
6. 書き出すファイル名、解像度・画質・音声保持を選んでMP4を書き出します。
7. 共有前に、書き出した動画を最初から最後まで確認してください。

## ビルド

Windowsで:

```bat
build-standalone.bat
```

初回だけ固定版 **MP4Box.js 2.4.1** をビルド時にダウンロードして `vendor/` にキャッシュし、そのコードを `dist/index.html` へ直接埋め込みます。実行時にCDNへ接続することはありません。

HTMLサイズを抑えるため、MP4Box.js はビルド時に gzip 圧縮してからBase64で内包します。ONNX Runtime WebのJavaScript、WASM、YuNetモデルもgzip内包し、起動時にブラウザ標準の `DecompressionStream` で展開します。元のライブラリ/モデルのバイト列は変えないため、顔検出精度や操作UIは変わりません。

生成物:

```text
dist/
├─ index.html
├─ dependency-manifest.json
├─ index.self-extract.html
├─ self-extract-manifest.json
└─ .nojekyll
```

依存を再取得する場合:

```powershell
.\build-standalone.ps1 -RefreshDependencies
```

自己解凍版を省略する場合:

```powershell
.\build-standalone.ps1 -SkipSelfExtract
```

## 対応形式

### 映像

v1は **H.264/AVC (`avc1.*` / `avc3.*`)** と **H.265/HEVC (`hvc1.*` / `hev1.*`)** の入力に対応します。HEVCはWebCodecsの実装が端末・OS・ブラウザに依存するため、読み込み時に `VideoDecoder.isConfigSupported()` で実際の動画ごとに確認します。

Pixel等で見られる `hvc1.1.6.L123` のように末尾のconstraint fieldが省略されたcodec文字列は、WebCodecs互換性確認時に `hvc1.1.6.L123.00` も候補として試します。H.264の `avc1.640033` も従来どおり有効なAVC入力として扱います。

読み込み時に次の3項目を個別表示します。

1. WebCodecs API (`VideoDecoder` / `VideoEncoder`) の有無
2. 入力動画の実際のcodec/profile/level・解像度を使った `VideoDecoder.isConfigSupported()`
3. 現在選択している書き出し解像度を使った `VideoEncoder.isConfigSupported()`

そのため、たとえば4Kの元解像度書き出しだけ非対応でも、入力動画の顔解析は続行でき、1080p / 720pへ切り替えて書き出し可否を再判定できます。

### 音声

AAC (`mp4a`) でMP4Box.jsから `esds` 設定を取得できる場合、圧縮済み音声サンプルをそのまま新しいMP4へコピーします。それ以外の音声はv1では再エンコードせず、警告のうえ無音で書き出します。

## 処理構成

```text
MP4/MOV
  ↓ MP4Box.js demux
H.264 / H.265 samples
  ↓ WebCodecs VideoDecoder
VideoFrame
  ├─ 解析パス: YuNet (1/2/5/10 fps + 最終実フレーム) → face tracks → interpolation
  └─ 書出パス: Canvasでマスク → VideoEncoder (H.264)
                                      ↓
AAC samples ─────────────── 無変換コピー ─┤
                                      ↓
                                MP4Box.js mux
                                      ↓
                                     MP4
```

## プライバシー

- YuNetモデル、ONNX Runtime Web、WASMはHTMLに内包します。
- MP4Box.jsもビルド時にHTMLへ内包します。
- `connect-src 'none'` で実行時のネットワーク接続を遮断します。
- 選択した動画・音声をアプリがアップロードする処理はありません。

## 制限事項

- AV1、VP9入力はv1では対象外です。
- H.265/HEVC入力は、端末・OS・ブラウザがWebCodecs HEVCデコードを提供している場合のみ利用できます。
- 書き出しは入力がH.264でもH.265でもH.264 MP4です。選択解像度でH.264エンコードできる必要があり、解像度変更時に再判定します。
- 長時間・4K動画はメモリを多く使用します。v1では抽出した圧縮サンプルとエンコード結果をメモリ上に保持してからmuxするため、長い動画ではメモリ使用量が増えます。
- 回転メタデータや特殊なMOV構成は今後の改善対象です。
- 顔が一時的に隠れる、急に向きが変わる、極端に小さい等の場合はトラックが分断されることがあります。
